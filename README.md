# 🍡 Mochi: your NEET PG study buddy

Mochi helps medical students practise, revise and keep going every day: AI doubt solving, exam-style MCQs and grand tests, spaced-repetition flashcards, clinical cases and vivas, focus rooms with friends, and sync between your PC and phone.

## Download

Get the newest version from **[Releases → Latest](https://github.com/mohammednab50-ship-it/mochi-releases/releases/latest)**:

| You want | Download |
|---|---|
| **Mochi Beta for Windows** (testers) | `Mochi-Beta-Setup-<version>.exe` |
| **Mochi Beta for Android** (testers) | `Mochi-Beta-<version>.apk` |
| Mochi for Windows | `Mochi-Setup-<version>.exe` |
| Mochi for Android | `Mochi-<version>.apk` |

Mochi Beta needs an invite code from the person who invited you. Type it once in **Settings → Mochi's brain**.

**Install once; updates are automatic.** After the first install, Mochi updates itself whenever a new version comes out.

### First-install notes

- **Windows:** if you see *"Windows protected your PC"*, click **More info → Run anyway**. The installer isn't code-signed yet.
- **Android:** open the downloaded APK. If asked, allow your browser or file manager to **install unknown apps**, then tap **Install**.
